# Ok Snack

**Gestão de pedidos para lanchonetes e restaurantes, simples e na nuvem.**

O Ok Snack é uma plataforma SaaS multi-tenant: cada estabelecimento tem
seu ambiente isolado para gerenciar pedidos, cardápio e estoque em tempo real.

Um produto da **[Codíco Tecnologia](https://codico.com.br/)**, software house
de Conceição do Coité – BA.

## 🧩 O que fazemos
- Controle de pedidos do balcão à entrega
- Cardápio e produtos gerenciáveis
- Estoque com controle de concorrência
- Multi-estabelecimento com isolamento de dados

## 🛠️ Stack
Node.js · MySQL · Docker · PM2 · Cloudflare
